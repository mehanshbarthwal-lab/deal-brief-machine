# Context Handoff

## Current Phase
Finalizing the Deal Brief AI generation pipeline and UI/UX refinements.

## Where We Are
- We have a fully functional web app running on `server.js` and `public/index.html`.
- Users can upload documents, parse them via AI, fill out a deal brief form, and click "Execute Pipeline" to run a multi-agent processing pipeline that streams markdown output.
- Users can click "Download PDF" to convert the final markdown into a fully formatted PDF.

## What Was Completed in the Last Session
1. **AI LaTeX Implementation:** Implemented a backend endpoint (`/api/generate-latex-source`) that uses an AI model (like `gemini-2.5-flash`) to generate clean, syntax-escaped LaTeX from the final Markdown output.
2. **Tiered Fallback PDF Engine:** 
   - Integrated `texlive.net` to compile the LaTeX.
   - Added a 12-second `AbortController` timeout to the LaTeX AI fetch request.
   - Designed a robust fallback mechanism: if the LaTeX generation times out, or the `texlive.net` compiler is unreachable, the system silently catches the error and falls back to a fast, client-side `html2pdf` generator.
   - Prevented the raw `.tex` file from being downloaded on fallback (so users only receive a PDF, per user requirements).
   - Refined the UX toast notifications so fallbacks are displayed as "info" messages (e.g., "Optimizing format. Generating fast standard PDF...") rather than scary errors.
3. **UI / Scrolling Glitches Fixed:**
   - Modified the "Execute Pipeline" scroll-to-progress logic to only occur on mobile (`window.innerWidth < 1024`). This prevents a jarring jump on large desktop screens where the left/right columns are side-by-side.
   - Added a "Downloading..." animated dot sequence to the PDF button while the AI LaTeX operates.

## Decisions Made
- **No Direct "PDF vs LaTeX" UI Toggle:** The user explicitly requested removing the toggle for users and making it an automatic fallback chain (try LaTeX first, then HTML2PDF).
- **No `.tex` file drops:** The user explicitly requested "i dont want tex file i want a proeprly combined pdf or compiled pdf otu of it please", so if compilation fails, we only generate the fallback PDF and do not give the user a `.tex` file.
